# XMPL React Sample

Sample site showing how to use [xmpl-react](./xmpl-react-1.0.0.tgz) in a React app. Built with [Vite](https://vite.dev/).

## Requirements

Node.js 20.19+ or 22.12+.

## Setup

```bash
npm install
```

The XMPL project settings (`xmpcfg`) are in `src/index.jsx`. Replace the access token, URL and Circle project details with your own project's values.

## Available Scripts

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser. Add `?rid=<recipient ID>` to the URL to load a recipient's personalized data.

The page reloads when you make changes.

### `npm run build`

Builds the app for production to the `build` folder.

### `npm run preview`

Serves the production build locally so you can check it before deploying.
